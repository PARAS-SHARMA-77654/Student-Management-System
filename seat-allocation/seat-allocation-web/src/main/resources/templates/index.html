Seat Allocation Engine

Event Seat Allocation Engine

Upload your registration list, choose how many seats the event has, and get a confirmed list and a waitlist. Seats are given strictly first come, first served, based on each person's registration timestamp.

Error message

Leave this empty to try the built-in sample list of 10 students.

CSV format

The file needs a header row with these three columns:

name,email,timestamp
Sheema Shariq,sheema25@jmi.ac.in,2026-08-18 09:12:00
Priya Singh,priya@jmi.ac.in,2026-08-18 09:45:00

Timestamps use the format yyyy-MM-dd HH:mm:ss. Rows can be in any order.

How it works

Every registration goes into a min-heap ordered by timestamp, so the earliest one is always at the top. Registrations are then taken off the heap one by one: the first ones fill the available seats and everyone after that joins the waitlist.

OperationCost
